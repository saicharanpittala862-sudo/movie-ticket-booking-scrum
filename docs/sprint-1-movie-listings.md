
# Sprint 1: Movie Listings

## Sprint Goal
Allow users to browse movies and view their details and show timings.

## Sprint Backlog
1. Display movie names and posters.
2. Display movie descriptions and genres.
3. Show available theatres.
4. Display show timings.
5. Review the movie listing requirements.

## Expected Increment
A movie listing feature that displays movies, their details, and available show timings.

## Acceptance Criteria
- Movie names are displayed.
- Movie details are available.
- Show timings can be viewed.

## Sprint Review
Demonstrate or review the planned movie listing functionality and collect feedback.
