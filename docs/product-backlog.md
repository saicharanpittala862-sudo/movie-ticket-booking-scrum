
# Product Backlog

The Product Backlog contains the prioritized requirements of the Online Movie Ticket Booking System.

| ID | User Story | Priority | Story Points |
|---|---|---|---:|
| US01 | As a user, I want to browse movies. | High | 3 |
| US02 | As a user, I want to view movie details and timings. | High | 2 |
| US03 | As a user, I want to select seats. | High | 5 |
| US04 | As a user, I want to view the total ticket price. | High | 2 |
| US05 | As a user, I want to pay online. | High | 5 |
| US06 | As a user, I want to receive an E-ticket. | High | 3 |
| US07 | As a user, I want to view booking history. | Medium | 2 |
| US08 | As a user, I want to search for movies. | Medium | 3 |

## Prioritization
High-priority features are implemented first because they are essential to the booking process.

## Estimation
Story points represent the relative effort required to complete each user story.
