
# Problem Statement

## Project Title
Online Movie Ticket Booking System

## Introduction
The Online Movie Ticket Booking System allows users to book movie tickets online.

## Problem
Customers may need to visit cinema counters or wait in queues to book tickets. They need a convenient way to browse movies, select seats, pay online, and receive tickets.

## Objectives
- Browse available movies.
- View movie details and show timings.
- Select available cinema seats.
- Calculate the ticket price.
- Make online payments.
- Generate electronic tickets.

## Proposed Solution
We propose an online system that combines movie listings, seat selection, payment processing, booking confirmation, and E-ticket generation.

## Methodology
We will use Agile Scrum to organize the work into sprints, review progress, and improve the system through team feedback.

## Expected Outcome
A planned system that provides a convenient movie ticket booking process.
