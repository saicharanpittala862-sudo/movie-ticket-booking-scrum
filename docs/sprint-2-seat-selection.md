
# Sprint 2: Seat Selection

## Sprint Goal
Allow users to select available cinema seats.

## Sprint Backlog
1. Design a theatre seating layout.
2. Display available and booked seats.
3. Allow users to select seats.
4. Calculate the total ticket price.
5. Prevent duplicate seat bookings.

## Expected Increment
A seat selection feature showing selected seats and the total ticket price.

## Acceptance Criteria
- Seat availability is displayed.
- Users can select available seats.
- The total price is calculated correctly.
- Already booked seats cannot be selected.

## Sprint Review
Review the planned seat selection workflow and collect feedback.
