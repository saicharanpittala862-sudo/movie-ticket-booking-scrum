# Online Movie Ticket Booking System

## Case Study 6 – Agile & Scrum Simulation

### Project Description
This project describes an online movie ticket booking system developed using the Agile Scrum methodology.

### Features
- Movie listings and show timings
- Cinema seat selection
- Online payment processing
- E-ticket generation

### Team Size
4 Members

### Methodology
Agile Scrum

### Project Deliverables
- Product Backlog
- Sprint Backlogs
- Sprint Reviews
- Definition of Done
- Sprint Retrospective
- Final Increment
