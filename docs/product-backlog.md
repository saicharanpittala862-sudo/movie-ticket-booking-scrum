# Sprint 1 — Movie Listings

## Sprint Goal

Enable users to browse available movies, view movie details, check show timings, and search for movies.

## User Stories

### US01 — Browse Movies
**Priority:** High  
**Story Points:** 3

As a user, I want to browse available movies so that I can choose a movie to watch.

**Acceptance Criteria**
- Display available movies with their titles and basic details.
- Allow users to select a movie to view more information.
- Do not offer unavailable movies or shows for booking.

### US02 — View Movie Details and Timings
**Priority:** High  
**Story Points:** 3

As a user, I want to view movie details, languages, formats, and show timings so that I can select a suitable show.

**Acceptance Criteria**
- Display the movie description, language, duration, and format when available.
- Display available cinema locations and show timings.
- Allow users to select an available show.

### US08 — Search Movies
**Priority:** Medium  
**Story Points:** 3

As a user, I want to search movies by title, genre, or language so that I can quickly find a suitable movie.

**Acceptance Criteria**
- Allow users to enter a movie search term.
- Show matching movies.
- Display a helpful message when no movies match the search.

## Sprint Tasks

1. Create the movie listings page.
2. Display movie information.
3. Add movie details and show timings.
4. Implement movie search.
5. Test the page and fix issues.

## Definition of Done

- The implemented features meet their acceptance criteria.
- The page is tested in a browser.
- Code changes are committed to GitHub.
- The team reviews the work before merging it into the main branch.

## Sprint Review

At the end of the sprint, demonstrate movie browsing, viewing details, and searching. Record incomplete work for a future sprint.
